# Evaluator design and ownership

XPathExpression owns the verified compiler's immutable AST and original whole-expression span. Compile uses the cancellable static-context constructor. Evaluate validates charged XmlNode connectivity, copies dynamic bindings/limits, captures the entire input document through the verified budgeted navigator, then rebinds context and every variable identity before executing AST. No user function runs during snapshotting. XmlNode context binding scans ancestry and logical text predecessors under the entry budget rather than calling the public unbudgeted metadata factory.

Execution uses iterator continuations on an explicit linked frame chain. Child AST requests suspend their parents; unary, binary, call arguments, filters, path inputs and nested predicates never recurse on the CLR stack. Per-evaluation requests, continuations, frames, bindings, selection scratch, navigator snapshot and result arrays are owned allocations. This design makes no zero-allocation claim for Compile or Evaluate. Existing borrowed primitive gates belong to their verified lanes. Evaluator measurement must separately disclose setup/compilation/whole evaluation and retained expression/result ownership.

Step predicates retain axis proximity order with freshly computed position/size at every predicate stage. Each origin's step result joins a sorted deduplicated document-order set only after predicates. Filter predicates consume document-order node-sets. Union performs identity-aware duplicate suppression before growth; all path/filter/union results use the entry navigator's normalization and model-owned result constructor. Attributes/namespaces/text runs retain the verified model identities.

Node-set/boolean comparisons convert the entire set to boolean for all six operators, including relational comparisons. Numeric/string conversions and core calls use the production function library and shared budget; all comparisons implement XPath boolean-first scalar and existential node-set rules, including independent existential !=. Engine-only function and normalization exception handlers attach the current AST/call span. User extension invocation occurs outside these handlers, so even callback-thrown engine exceptions retain identity. All extension returns are capped and normalized/rebound after cancellation polling. Public callback arguments are immutable arrays.

Evaluator binding lookup compares expanded names through charged character loops rather than hashing caller-sized names in another engine-owned dictionary. Selection scratch checks logical node-set size before appending and copies geometric growth through explicit per-entry polling. Frame/argument/literal/variable/predicate/axis/result work is charged; string and name comparisons poll every inspected unit. Namespace/name metadata registration copies are handled by verified model context constructors. Representational capacities stay finite even when quotas are unlimited.

Snapshot copying requires caller-exclusive access to the tree. Extensions may mutate only after the entry capture; the running query retains its entry values/order/membership and live handles. Subsequent evaluations see the changed tree. Expression reuse/concurrency has no shared mutable evaluation state; user extensions remain responsible for their own thread safety and cooperative charging/cancellation.
