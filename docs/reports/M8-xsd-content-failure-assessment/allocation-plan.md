# Allocation probe scope

Source review precedes any preparation. Root releases offline probe build/control,
then grants a fresh durable lease for the frozen manifest. Root is the sole
measurement launcher; workers do not start counters without that grant.

Reuse the verified facade probe and lifecycle supervisor. Seven owned-output routes
cover valid local DOM; one failed sibling; 1025/2048 failed siblings; later datatype
failure; 1025 string validation; and genuine independent diagnostic refusal.
Every route asserts complete/valid/diagnostic count and consumes the result. Fixtures,
schema compilation and instance generation are outside warm route counters.
Sixteen warmups precede 64 measured synchronous operations per route. Separately
measure cold fixture setup, one positive 1024-byte allocation control and whole-heap
retention with 16 one-error results kept alive. Whole-heap delta is illustrative,
not a per-object retained-size or leak claim. DOM traversal/context/results/diagnostics
own allocations; the extra frame bool has no new allocation site. No zero-allocation
claim is made for complete validation. No BDN/timing/x64/async/full-corpus claim.

--control disables all allocation/heap reads. Source hashes freeze runtime, own tests,
probe/check/supervisor/build inputs, runtime binaries, disabled output and launch commands.
The reused supervisor has 30s maximum, 20s work and 10s cleanup reserve. Root supplies
a fresh grant with latest start +60s and absolute expiry +90s; a late start never extends it. It checks
identities before and after, reaps its children, kills/drains owned groups, closes logs,
and writes durable release before raw result inspection. No retries or output overwrite.
