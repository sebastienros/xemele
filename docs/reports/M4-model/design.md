# M4 model boundaries

The public model follows the frozen M4 declarations, excluding the XPathExpression facade owned by M4-evaluate. AST, navigator/compiler/function interfaces and core signatures have no dependency on future implementation types.

XPathItem stores immutable metadata separately from stable live tree handles. Attribute identity uses its never-reused attribute slot; namespace identity uses owner plus ordinal prefix. Logical text coalesces maximal adjacent Text/CData runs, including an empty first physical member, and rejects empty aggregates. Public factories are explicit unbudgeted materialization. The internal captured-fields constructor does not traverse or reread live state: the navigator can preflight its budget and construct items from its entry snapshot. Handles retain the whole owner document by design. Metadata strings are immutable owned references; no borrowed buffer is retained.

FromNodeSet enumerates once, snapshots membership, removes identity duplicates and sorts using one captured document topology. It rejects foreign documents and identities absent from the current logical tree, retaining supplied item metadata. This explicit public materialization has no Evaluate budget. Snapshot results preserve their order, membership and strings after mutation; later materializations see new topology.

AST constructors snapshot each collection into read-only owned storage; getter-only properties prevent clones from bypassing constructor validation. NamespaceWildcard has a discriminator-specific internal payload: nonempty resolved URI and empty LocalName. Only the internal factory creates it. Name tests and public registration/variable/function boundaries reject this payload and require valid NCNames; node/PI tests reject unused names and unrelated PI payloads. This internal encoding was confirmed by the coordinator without changing frozen public contracts.

Numeric conversion uses borrowed spans with direct ASCII grammar validation, XML-S trimming and invariant .NET double parsing. No vocabulary hashing/SearchValues optimization is introduced. Number formatting uses shortest round-tripping R digits and expands exponents at an explicit owned string boundary, including subnormal and maximum doubles. Boolean and string primitives preserve XPath scalar conversion semantics. The scalar microbenchmarks compare borrowed parsing with the same parser after explicit owned string materialization; they do not claim a tokenizer/query composition optimization.

Static and dynamic contexts copy caller dictionaries; limits are immutable validated records. Static context includes only implicit xml plus validated bindings and approved core/extension signatures. ContextTokens/ContextCharacters expose option-copy charges so the compiler can add lexical/expression charges under the same quotas. The shared evaluation budget checks limits before increment/growth, catches counter overflow, and polls cancellation on every charge (including zero), exceeding the frozen polling frequency. FunctionContext uses a real injected focus and budget; it does not expose placeholder behavior. Extension implementation exceptions remain caller exceptions because these seams have no catch/translation layer.

Model tests are runtime tests. They do not claim grammar, axis, function or expression conformance owned by later lanes. Performance evidence remains provisional until query composition; Arm64 timing is informational, with M9 x64/Arm64 confirmation outstanding.

Independent source review at 6374aa1 found two lane-composition defects, fixed in one batch: snapshot result construction and context copy work accounting. FromSnapshotNodeSet accepts already normalized navigator snapshot items, preflights node-set size and copy operations before destination growth, then polls while copying owned membership without reading any live handle metadata/topology. It intentionally trusts the internal normalized ordering/deduplication precondition. Public FromNodeSet remains live-document materialization. Dynamic context copying charges each registration entry and scanned name/URI code unit against the shared operation budget, checks incoming scalar/node-set limits before insertion, and polls both supplied context cancellation and shared budget. Static options enumerate extension registrations directly, charge token/character caps before validation/copy, and poll each entry and during name/URI validation. ContextScan reuses verified M2 XML scalar/name classification with NCName colon exclusion. These entry points permit compiler/evaluator-owned budgets and whole-expression diagnostics without future production dependencies.
