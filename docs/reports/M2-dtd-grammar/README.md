# DTD grammar integration join

This task validates the verified common-only model, framing, value and parser
children. It owns no runtime source and preserves the approved DTD contract.
The sample directly compiles those sources with common limits, diagnostics and
scalar locations; it has no resolver, input decoder, core, DOM or later milestone
implementation dependency. Its effective table is demonstration composition,
not a production DOCTYPE/entity context.

The fresh verifier compares all twenty actual approved DTD types against an
independently compiled `Dtd.cs.fixture`, including constructor visibility,
nullability, parameter names/defaults, interfaces and record members. It compiles
a real nullable property mutation to prove the inventory detects a changed
contract. Public runtime ABI comparison remains separate.

Nineteen direct test rows include nine private pinned external subset resources
with hashes, original case IDs and independently authored declaration models.
They exercise every short UTF-16 split. Five joined table cases prove that
forbidden external local entities defer validation until internal declarations
can override them, while an unchanged negative effective table still rejects.
Additional loops prove every framed declared/absent split, absolute scalar/byte
locations, exact/one-over aggregate quotas spanning framing, parser and default
application, pushed-source parent restoration, overwritten borrowed buffers,
and accepted-entry cleanup on cancellation, faults and refusal. Existing child
malformed/recursive/conditional/content-model/source/depth tests are rerun in the
fresh cumulative suite rather than copied or weakened.

`verify.py --report-prefix <unique-name> --expected-branch codex/m2-dtd-grammar`
runs Release builds, direct and MTP/discovery checks, the common-only sample,
approved API comparison/mutation, untimed full composition oracles, allocation
probe, a fresh complete copied BCL reference runner, pinned provenance, registry,
planning tests/validation and committed/staged/working/untracked ownership and
whitespace audits. Run with the pinned .NET 10 SDK on PATH. Historical failures
are preserved in uniquely named reports, with no passing claims for unrun work.

The new single BenchmarkDotNet workload measures owned two-subset parsing,
effective-table merging and normalized-default outputs. It uses MemoryDiagnoser
and ShortRunJob; fixture constants exist before timing, and full model/default
oracles run outside the interval. Timing requires the coordinator's exclusive
grant. It is illustrative Arm64 composition evidence, not a throughput target,
large-table scaling result, full XML entity/DOCTYPE benchmark, or Windows/x64/AOT
claim. Child timing archives remain unchanged and are not rerun. The allocation
probe reports cold setup and aggregate warm owned synchronous allocations; it
also records a separate informational retained-GC estimate for 100 composed
outputs; it makes no zero-allocation composition promise. Child warm
borrowed primitives have separately verified allocation evidence.

The retained estimate includes each boxed `(DtdModel, string[])` tuple holder
and the outer `object[]`, in addition to the immutable model/default outputs.
Candidate-four raw output is preserved; the initially incomplete label is
corrected here and in the sample without rerunning an unchanged allocation
workload. The strengthened benchmark oracle checks every expected frozen field
and all exact scalar locations (character input has null URI/byte offsets).
