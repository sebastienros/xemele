# RELAX NG lexical repair source candidate

Primary sources independently reviewed: [RELAX NG 3 December 2001 §§3,4.3](https://relaxng.org/spec-20011203.html), [RFC2396 Appendix A](https://www.rfc-editor.org/rfc/rfc2396), [RFC2732](https://www.rfc-editor.org/rfc/rfc2732), [Namespaces in XML 1999](https://www.w3.org/TR/1999/REC-xml-names-19990114/), and [XML 1.0 Second Edition Appendix B](https://www.w3.org/TR/2000/REC-xml-20001006).

The original coordinator brief incorrectly prohibited any XLink escape projection. On primary-source review the coordinator corrected A1: the normative projection precedes absolute/nonfragment URI grammar checking. Raw Unicode and space are accepted in the URI body when projection admits them. Malformed existing percent escapes remain invalid; a scheme requires an ASCII letter first; the body must satisfy the nonempty opaque or hierarchical alternative; literal fragments are forbidden. Escaped fragment characters are data. No per-scheme System.Uri normalization occurs. Empty libraries remain supported.

Read-only inspection of TextBinaryUri confirmed strict UTF-16 decoding, metered scans, percent-triplet checking, projected atoms, RFC2396 path/query/authority alternatives and RFC2732 bracketed IPv6 handling. It accepts relative/fragment references, so Compiler.cs separately checks the scheme and literal fragment prohibition. The projected library string is persisted for datatype identity, with one reserved final string only when required. No shared helper changes.

Name checks now use immutable historical XML start/continuation ranges through TextBinaryNames, excluding colon. U+0E35 is continuation only; supplementary letters admitted by modern XML names are excluded. Every existing CheckName call (element/attribute QName, name content, grammar ref/parentRef/define, datatype type and parameter name) retains its stage and grammar coverage, including discarded patterns.

One operation adapter is owned by each compilation, preserves lexical node locations and delegates work/cancellation to the same ledger. Name lookup charges logarithmically per scalar. URI passes are linear in input length, including projection, with constant-bounded UTF-8 scratch. No SearchValues optimization or speed claim is proposed. Inherited-library rechecking and syntax/parse repetition remain bounded and charged. Escaping computes a checked output length, reserves one owner plus 256-unit components before allocation, and fills one string through a static string.Create callback charging every output character, including all prefix characters and each of three %HH characters per UTF-8 byte. The new per-compilation adapter reserves its owner before construction. ASCII input retains its owner and has no output reservation. Independently derived work/component boundaries and cancellation inside emitted escapes cover an ASCII prefix plus space, é, and a supplementary scalar; these corrected tests passed in the final 80-case owned repair suite and 405-case affected run. Controlled allocation evidence was completed under the fresh coordinator grant and independently accepted after durable release; see allocations.md.
