## Parallel lanes

Tasks with disjoint ownership and satisfied prerequisites can run concurrently. These topological waves show the internal joins; external prerequisites in the table still apply.

- Wave 1: `M8-contracts`.
- Wave 2: `M8-resource-kind` and `M8-xpath-accounting`, then `M8-model`.
- Wave 3: `M8-regex`, `M8-datatypes-core`, `M8-rng-compile`, `M8-xsd-compile`, `M8-sch-compile`.
- Datatype sub-lane: after the core, numeric/temporal/text-binary children can run independently; `M8-datatypes` composes all verified children before facets start.
- Wave 4: `M8-facets`, `M8-xsd-content`, `M8-sch-validate`.
- Wave 5: `M8-rng-validate`, `M8-xsd-validate`, `M8-xsd-identity`, `M8-sch-report`.
- Wave 6: `M8-rng-corpus`, `M8-xsd-facade`, `M8-sch-corpus`.
- Wave 7: `M8-xsd-corpus`.
- Wave 8: `M8-cli`.
- Wave 9: `M8-gate`.

## Additive exit

Verify cumulative product plus every advertised schema profile; no release-task API required.

No dependency may point to a later milestone. Earlier checks stay required. A gate verifies the integrated combination, including functionality from the preceding gate. In-progress branches and public stubs cannot satisfy it.

## Ownership and integration

Each task lists its source, tests, API fragment, and report ownership. Shared contract changes finish first. Branch workers update only their own task record; the coordinator verifies integration before unlocking dependents. See the [workflow](../tasks/README.md).

Source-provenance repair: `M8-source-locations` verifies before RNG/Schematron compilation and the gate. Active XSD composition work can proceed independently; add its repair dependency after verification before consuming the new helper.

Resource-identity repair: `M8-schema-resource-base` preserves the frozen reference/interface while separating effective inherited `xml:base` from final referring resource URI. Schematron compilation and both public schema facade lanes require this verified repair; prior compiler evidence remains historical.

Wildcard composition repair: active content owns its source but waits on the shared compiler repair. Add the ordered dependency after verification; facade/gate closure already requires the repair.
