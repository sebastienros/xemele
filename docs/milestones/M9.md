## Parallel lanes

Tasks with disjoint ownership and satisfied prerequisites can run concurrently. These topological waves show the internal joins; external prerequisites in the table still apply.

- Wave 1: `M9-contracts`.
- Wave 2: `M9-api`, `M9-performance`, `M9-distribution`, `M9-robustness`.
- Wave 3: `M9-gate`.

## Additive exit

Verify all cumulative gates, API/performance/package/robustness evidence and resolved repair dependencies at final integrated revision.

No dependency may point to a later milestone. Earlier checks stay required. A gate verifies the integrated combination, including functionality from the preceding gate. In-progress branches and public stubs cannot satisfy it.

## Ownership and integration

Each task lists its source, tests, API fragment, and report ownership. Shared contract changes finish first. Branch workers update only their own task record; the coordinator verifies integration before unlocking dependents. See the [workflow](../tasks/README.md).
