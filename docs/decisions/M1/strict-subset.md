# Strict XML subset freeze

Owner M1-contracts. Exact declaration and usage files are under
`tests/Contracts/Fixtures/M1/`; compiled projects are under
`docs/reports/M1-contracts/Projects/` with explicit .cs.fixture Compile links.
No declaration model enters src/Xemele or a package. Throwing declaration bodies
are never exercised as runtime behavior. M0 common declarations/models/goldens
are preserved unchanged. M0's minimal Name/Owner convenience members were model
helpers, not a shipped tree inventory; M1's exact production surface uses
LocalName/OwnerDocument. Public readonly XmlNode and XmlDocument names and arena
semantics match the approved representation decision.

Linking declarations in each independent project models internal assembly-local
interfaces without making implementation internals public or introducing
InternalsVisibleTo as a runtime ABI requirement. Projects have distinct model
assembly names; runtime namespaces/signatures are identical. Public metadata
snapshots under this task's fixtures are generated by the unchanged approved M0
ApiCheck normalizer. They are model baselines, not advertised shipped docs/api.
The checker only covers public families it understands; source compilation and
negative probes complement it for internal ref-struct/span/count interfaces.
No claim of unrestricted layout/interop/compiler-attribute compatibility is made.

Decisions fixed for consumers:

- Explicit default handles instead of nullable navigation. Never recycle slots;
  removed attribute/declaration handles retain owner/value but IsAttached=false.
  Membership changes invalidate owner-wide structural enumerators; value changes
  preserve position. Namespace declarations have separate ordered storage.
- Optional partial post-commit tree hook introduces no DTD/index type. Later
  modules own hook bodies and index failure/rebuild behavior.
- Decoder produces raw UTF-16 plus absolute original-byte mapping per code unit,
  with whole scalar emission; grammar owns newline/reference normalization.
  CompleteByteSource supplies EOF byte length that cannot be inferred from a
  scalar's start. Detection/carry/scratch are bounded owned state.
- Character input never round-trips through UTF-8 or receives fabricated byte
  positions/encoding. Generic UTF-16 requires BOM; explicit endian labels allow
  matching signature-selected byte order. Unsupported labels reject in M1.
- All lexical/document/start-tag/attribute/content/end callbacks pause after
  delivery. A validated tag's pending event sequence drains without re-reading
  source or replaying callbacks. No attribute view array/DOM allocation in core.
- Ref-struct views are borrowed only through callback return; generic sink is a
  reference-type operation owner, preventing mutable struct copies/boxing.
  EndDocument can pause exactly once; empty final resume completes it.
- Namespace output defaults Strict. Repair is explicit, deterministic temporary
  scope computation without tree mutation. String declarations omit encoding;
  byte declarations use actual encoding and separate explicit BOM policy.
  Mixed-content indentation never inserts whitespace next to text/CDATA.
- No M2 resolver/recovery/DTD model or M3 reader/writer/async declarations. M1
  DOM factories remain an independently composed partial module.

Lifetime/allocation reasoning: callback views, concrete collection enumerators
and parallel mappings admit borrowed, unboxed primitive work; signatures alone
do not prove 0 B. Decoder setup/4096-unit char and Int64 mapping scratch, bounded
start-tag/token/scope state, unique interned names, owned DOM values, diagnostics,
output strings and pool misses are separate explicit allocation boundaries.
No runtime hot path is implemented here, so no new timing slot or performance
victory is claimed. Runtime owners must measure warm/cold/retained paths and
composed XML before verification; M0 provisional arm64 results remain unchanged.

Normative grammar references: [XML 1.0 Fifth Edition](https://www.w3.org/TR/REC-xml/)
and [Namespaces in XML 1.0 Third Edition](https://www.w3.org/TR/xml-names/).
This contract fixes an explicitly bounded implementation slice, not full XML
conformance. M2 full grammar work retains visible corpus failures until verified.

See the report README for checks, evidence scope and exact remaining limitations.
