# RELAX NG pinned sources and independent oracles

Jing XML specification suite: [relaxng/jing-trang](https://github.com/relaxng/jing-trang/tree/a6bc0041035988325dfbfe7823ef2c098fc56597), revision `a6bc0041035988325dfbfe7823ef2c098fc56597`, BSD-3-Clause (`upstream/jing/copying.txt`). Original `spectest.xml`, `test/index.html` and splitting `prep.xsl` are preserved. `index.html` explicitly identifies the final December 2001 specification; the suite's legacy embedded October documentation is retained without alteration. `import_jing.py` follows the original splitter’s child-node/DTD/entity semantics, retaining namespace context and original schema/instance predicates. Ordinal IDs are stable for this pinned byte stream: 385 schema cases, 580 instance cases, 31 external resources; no excluded or missing cases.

libxml2 historical regressions: [GNOME/libxml2](https://gitlab.gnome.org/GNOME/libxml2/-/tree/96498992efa48d52b0e8b83058bd88dbdaf153c1/test/relaxng), revision `96498992efa48d52b0e8b83058bd88dbdaf153c1`, version 2.15.4, MIT (`libxml2/Copyright`). The selected family is every top-level numeric bug-ID schema, instance and auxiliary schema in `test/relaxng`: seven schemas, eighteen instance predicates, one external resource. Every historical predicate in this family is retained. The original `result/relaxng/*.err` files are licensed upstream expectation fixtures, not generated test execution logs. `runtest.c` is retained to verify their interpretation. Example/tutorial schemas and the duplicate OASIS suite belong to different upstream source families; this is a precise source selection, not an unsupported-feature exclusion.

`*-inventory.json` distinguishes schema accepted/rejected from instance valid/invalid, records each original/extracted byte hash and exact case applicability, and records zero missing cases/resources. No outcome was generated from Xemele. Independent pinned Jing and libxml2 invocations execute the same fixtures. The twelve libxml2 discrepancies are version/fixture/hash/spec pinned in `reference-limitations.json`; they are explicitly excluded from agreement counts, while Xemele is still required to meet each original expectation. Compact syntax is outside the advertised XML profile and is not part of these selected XML suites.

Seventeen additional authored datatype/facade witnesses (`profile-inventory.json`) cover ten datatype lexical spaces, NaN value equality, arbitrary integer facet bounds, conjunctive RNG patterns, and invalid regex/inapplicable/contradictory/unreachable value finalization. Their 28 validity predicates are specified independently in `generate_profile.py`; pinned Jing corroborates them. Three additional libxml2 schema-finalization limitations are separately retained, bringing the limitation ledger to fifteen. The public-facade tests also distinguish complete invalid results from malformed/quota/recovered-input incomplete results and preserve caller DOM/stream/source provenance. No authored witness replaces an upstream predicate.
