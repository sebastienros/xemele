# Frozen algorithm-specific canonical vectors

Thirty-two fixed vectors pin input/selection/options/exact UTF8 and hashes before
product execution. Six preserve earlier M5 fixtures; remaining cases cover
escaping, normalization, namespace context, XML inheritance and primary W3C
examples. Full/selected inclusive1.0 and exclusive1.0 reference cases use the
framework algorithms only in tests. Inclusive1.1 has exact normative fixtures;
no BCL1.1 support is claimed. W3C1.1 section3.8 explicitly uses official erratum
E11-01 (`bar/foo`), preserving the original published error explanation.

Coverage is finite and declared; this is not a complete canonicalization standard
suite. Reference comparisons never replace the independently pinned expected bytes.
